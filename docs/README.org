#+title: AtlasForge Documentation

For installation, configuration, deployment, and development instructions, see
the [[file:../README.org][project README]].

- [[file:example-atlases.org][Example atlases]] shows how to build an atlas from an HGNC group ID or a gene
  list using histone and HOX examples.

- [[file:benchmarks.org][Benchmarks]] covers build time, serving performance, browser rendering, storage,
